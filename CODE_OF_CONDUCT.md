# Code of Conduct

We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, keep feedback about the work, and make it easy for anyone to take part
regardless of background or experience. Harassment of any kind isn't tolerated.

Report problems to **support@aggregate.finance**. Reports are read by the maintainers only and kept confidential.
Maintainers may remove comments, code or contributors that break these rules.
