# Aggregate for Claude Code

Adds Aggregate (aggregate.finance), the read-only finance MCP server, to Claude Code. Your AI can then answer questions
about cash, burn and runway across your banks, cards, payment apps, books and payroll. It can't move money.

```sh
claude plugin install aggregate --marketplace Izzy-Gottz/aggregate-finance
```

Run `/mcp` to sign in. Free during beta. Docs: [docs.aggregate.finance](https://docs.aggregate.finance)
