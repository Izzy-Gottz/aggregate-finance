# Brand icons in the app

The rows in **More connections**, and connected sources, show a brand's icon only where this table says so. Every
other source keeps its letter tile.

Rules for every icon: the brand's own file, unaltered, on a white tile in both themes, the same 22px size. Nothing is
recolored, traced or redrawn. We never say "partnered with", "official" or "certified" unless that brand has granted it.
**If a brand objects, remove its icon.**

The logos in this folder are their owners' trademarks. They are used only to identify services you can connect, and
they aren't covered by this repository's AGPL license.

Terms and sources read 2026-11-01. Recheck before relying on them. Yisrael approved each decision and each download on
2026-11-01. This is a record of what we read, not legal advice.
